# Forge AI — vibecoding platform on free OpenRouter models

Describe an app in plain English and Forge builds it live in your browser — Lovable-style: chat on the left, a running preview of your app on the right. Follow-up messages edit the app; questions and small talk get conversational replies.

Everything runs on **free OpenRouter models** (primary: `poolside/laguna-xs-2.1:free`) with an automatic failover chain across the strongest free coding models.

## How it works

Free models can't match frontier models raw, so Forge wraps them in a staged pipeline that engineers the quality in:

1. **Intent classification** — deterministic heuristics + a tiny classifier decide whether a message is CHAT, CREATE, or EDIT. Saying "no" or asking a question never regenerates your app.
2. **Architect pass** — a compact JSON file plan (files + npm deps) before any code is written.
3. **Deterministic scaffold** — `package.json`, `index.html`, `src/main.jsx`, `src/index.css` are generated by code, never by the model.
4. **Constrained generation** — a strict file-block output protocol with a few-shot exemplar, parsed by a forgiving parser that tolerates sloppy model output.
5. **Validation** — every generated file is parsed with Babel, imports are resolved, missing npm deps self-heal into package.json.
6. **Auto-repair loop** — syntax/import errors are fed back to the model (up to 2 attempts) until the app runs.
7. **Failover** — rate limits and dead models fail over instantly through the chain; the live free-model list is re-discovered from OpenRouter at runtime.

Apps are real React projects (components + npm dependencies), run instantly in an in-browser bundler (Sandpack), and can be downloaded as a ZIP. Projects and chat history persist in localStorage; the server is fully stateless.

## Setup

```bash
cd frontend
npm install
```

Create `frontend/.env.local`:

```
OPENROUTER_API_KEY=sk-or-v1-...
```

> Get a free key at https://openrouter.ai/keys. If your key has ever been shared anywhere (chat, screenshots, commits), rotate it. Never commit `.env.local`.

Run:

```bash
npm run dev
```

Open http://localhost:3000, sign in with any email + 6-char password (demo auth), and describe an app.

### Offline / mock mode

For development without network access to OpenRouter:

```
FORGE_MOCK_AI=1        # scripted pipeline (todo app fixture)
FORGE_MOCK_AI=broken   # first generation has a syntax error → exercises the repair loop
```

Including `force429` in a message exercises model failover.

## Deploying (Vercel)

- Root directory: `frontend`
- Set `OPENROUTER_API_KEY` in the project's environment variables.
- Post-deploy smoke test: open `/chat`, ask for a small app ("build a counter app"), confirm the preview renders and a follow-up edit ("make the button red") changes only the styling. `/api/health` shows the active model chains. If `poolside/laguna-xs-2.1:free` is unavailable on OpenRouter, runtime discovery drops it and the next model in the chain takes over automatically.

## Engine layout

```
frontend/src/engine/     staged pipeline (intent, architect, scaffold, protocol, validate, repair, failover)
frontend/src/app/api/generate/route.ts   stateless SSE endpoint
frontend/src/hooks/use-project.ts        client state + localStorage persistence
frontend/src/components/workspace/       split-view UI (chat + Sandpack preview/code)
```
